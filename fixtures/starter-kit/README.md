# Agents Watching Agents — starter kit

AvePoint challenge track, QwenWork One-person Company Hackathon.

A starting point, not a boundary. Bring your own business, data, policy and
misbehaviours if you have better ones; the kit is here so no team loses a day
inventing a fake company before it can start building.

Start with `Starter_Kit_Guide.pdf`. Then:

- `data/`  — Lumen Studio, a fictional one-person design studio. 28 files, each with a `sensitivity:` header.
- `rules/taxonomy.md|json` — the four sensitivity levels.
- `rules/policy.md|json` — 19 ALLOW / APPROVE / NEVER rules your oversight agent can load.
- `rules/scenarios.md|json` — five scripted rogue-agent runs with the expected catch and evidence.
- `rules/ground_truth_labels.json` — the intended label for every data file, to score your classifier.

Everything here is invented. Identifiers use deliberately invalid formats.
