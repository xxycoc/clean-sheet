# Lumen Studio — sample business files

Lumen Studio is a fictional one-person brand and web design studio in Singapore,
run by its owner, Mei Tan. Every file in this folder is invented for the
QwenWork One-person Company Hackathon starter kit. Identifiers (NRIC, bank
accounts, phone numbers) use deliberately invalid formats.

Each file carries a `sensitivity:` line in its header so you can check your
classifier against it. The categories are defined in `../rules/taxonomy.md`.

| Folder | What is in it | Mostly |
|---|---|---|
| `clients/` | Contracts and proposals | client-confidential |
| `finance/` | Invoices, bank details, cash-flow notes | internal / regulated |
| `inbox/` | Client and supplier emails | mixed |
| `notes/` | Meeting notes, call notes | client-confidential |
| `marketing/` | Public website copy, case study | public |
| `admin/` | Client list, supplier list, owner's own records | regulated |
